# Отчёт: Классификация номерных знаков (Чистый / Грязный)

## 1. Описание задачи и обоснование подхода

### Постановка задачи

Задача — разработать модель **бинарной классификации изображений**, которая по фотографии автомобильного номерного знака определяет его состояние:

- **Класс 0 — cleaned (чистый):** текст хорошо читается, поверхность знака без загрязнений
- **Класс 1 — dirty (грязный):** знак покрыт грязью, снегом, пятнами; текст частично или полностью нечитаем

**Практическое применение:** системы автоматического пропуска на парковках и КПП используют OCR для распознавания номеров. Грязный знак блокирует работу системы. Классификатор позволяет заранее выявить такие случаи и запросить ручную проверку или направить автомобиль на альтернативный проезд.

### Описание данных

| Параметр | Значение |
|---|---|
| Тренировочная выборка | 40 изображений (20 cleaned + 20 dirty) |
| Тестовая выборка | 744 изображения (без меток) |
| Баланс классов | Идеальный (50% / 50%) |
| Форматы | JPEG |
| Размер | Вариативный (требует приведения к единому) |

## 2. Обоснование выбора методов, инструментов и архитектуры

### 2.1 Обоснование Transfer Learning

**Проблема малого датасета.** 40 изображений — критически мало для обучения свёрточной нейросети с нуля. Модель с миллионами параметров мгновенно запомнит тренировочные данные (переобучение), но не сможет обобщать на новые примеры.

**Решение — Transfer Learning (перенос обучения):**

Используем модель **EfficientNet-B0**, предобученную на ImageNet (1.2 миллиона изображений, 1000 классов). Эта модель уже научилась извлекать универсальные признаки изображений: края, текстуры, формы, паттерны. Для нашей задачи особенно важно, что модель умеет отличать:
- Чёткие текстуры от размытых
- Равномерные поверхности от загрязнённых
- Высококонтрастные объекты от объектов с низким контрастом

### 2.2 Почему EfficientNet-B0?

| Модель | ImageNet Top-1 | Параметры | Скорость |
|---|---|---|---|
| VGG-16 | 71.5% | 138M | Медленно |
| ResNet-50 | 76.1% | 25M | Средне |
| **EfficientNet-B0** | **77.1%** | **5.3M** | **Быстро** |
| EfficientNet-B3 | 81.6% | 12M | Средне |

EfficientNet-B0 достигает наилучшей точности при минимальном числе параметров. Меньше параметров = меньше риск переобучения при малом датасете.

**Принцип EfficientNet:** масштабирование глубины, ширины и разрешения сети одновременно и в правильном соотношении (Compound Scaling), что обеспечивает оптимальную эффективность.

### 2.3 Стратегия двухфазного обучения

```
Фаза 1: Backbone заморожен
├── Обучаем только: Dropout → Linear(1280, 2)
├── LR = 1e-3 (высокий, т.к. голова инициализирована случайно)
├── 30 эпох
└── Цель: быстро адаптировать голову к нашей задаче

Фаза 2: Fine-tuning (всё разморожено)
├── Backbone LR = 1e-5 (очень маленький — не портим предобученные веса)
├── Classifier LR = 5e-5 (чуть больше)
├── 30 эпох + CosineAnnealingLR
└── Цель: тонкая подстройка признаков под нашу специфику
```

## 3. Ключевые этапы работы

### 3.1 Разведывательный анализ данных (EDA)

**Визуальный анализ** всех 40 тренировочных изображений позволил выявить:

- Чистые знаки: равномерный светлый фон, чёткие тёмные буквы и цифры
- Грязные знаки: неравномерная окраска, размытие, пятна, иногда только часть знака видна

**Анализ размеров:** изображения имеют разные размеры → необходимо приводить к единому (224×224 для EfficientNet).

**Баланс классов:** датасет идеально сбалансирован (50/50) → не нужно взвешивать классы.

**Анализ яркости:** грязные знаки в среднем имеют более низкую и неравномерную яркость — это потенциальный признак для классификации.

### 3.2 Предобработка данных

**Нормализация:**
Используем статистику ImageNet (`mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`), поскольку модель предобучена на этих параметрах. Отступление от них ухудшило бы качество признаков.

**Аугментация тренировочных данных:**

| Трансформация | Параметры | Обоснование |
|---|---|---|
| RandomHorizontalFlip | p=0.5 | Симметричность задачи |
| RandomRotation | ±15° | Разные углы установки камеры |
| ColorJitter | brightness=0.3, contrast=0.3 | Разные условия освещения |
| RandomAffine | translate=10%, scale=90-110% | Разные расстояния и позиции |
| RandomGrayscale | p=0.1 | Инвариантность к цвету |

Аугментация искусственно увеличивает эффективный размер обучающего набора и помогает модели не запоминать конкретные примеры.

**Разбивка train/val:** стратифицированный split 80/20 (32 train + 8 val) сохраняет баланс классов в обоих сплитах.

### 3.3 Архитектура модели

```
Input: [B, 3, 224, 224]
    ↓
EfficientNet-B0 features (предобученный backbone)
    ↓ MBConv blocks (Mobile Inverted Bottleneck)
    ↓ Squeeze-and-Excitation блоки
    ↓
AdaptiveAvgPool2d → [B, 1280]
    ↓
Dropout(0.4)  ← регуляризация
    ↓
Linear(1280, 2)  ← классификатор
    ↓
Output: [B, 2]  (logits для CrossEntropyLoss)
```

**Dropout(0.4):** случайно "выключает" 40% нейронов во время обучения, заставляя модель не полагаться на конкретные признаки. Это мощный регуляризатор.

### 3.4 Гиперпараметры и регуляризация

| Гиперпараметр | Значение | Обоснование |
|---|---|---|
| Batch size | 8 | Малый датасет — маленький batch |
| Phase 1 LR | 1e-3 | Стандарт для Adam при обучении с нуля |
| Phase 2 LR (backbone) | 1e-5 | Очень малый — не портим предобученные веса |
| Phase 2 LR (head) | 5e-5 | Чуть больше для финальной подстройки |
| Weight Decay | 1e-4 | L2-регуляризация против переобучения |
| Dropout | 0.4 | Выше стандартного (0.2) из-за малого датасета |
| Input size | 224×224 | Стандарт для EfficientNet-B0 |
| Optimizer | Adam | Адаптивный, быстрее сходится чем SGD |

**Scheduler:**
- Фаза 1: StepLR (делим LR на 2 каждые 10 эпох)
- Фаза 2: CosineAnnealingLR (плавное убывание по косинусу)

## 4. Оценка модели и визуализация результатов

### 4.1 Метрики на валидационной выборке

> *Значения будут получены после запуска ноутбука*

| Метрика | Значение |
|---|---|
| Accuracy | — |
| Precision | — |
| Recall | — |
| F1-score | — |
| ROC-AUC | — |

**Интерпретация метрик:**

- **Accuracy** — базовая метрика. Из-за сбалансированных классов является надёжным показателем.
- **Precision** — важна если критична ложная тревога (система ошибочно классифицирует чистый знак как грязный → лишняя задержка на КПП).
- **Recall** — важна если критично пропустить грязный знак (пропущенный грязный знак → сбой OCR → потеря данных о транспорте).
- **F1-score** — компромисс между Precision и Recall.
- **ROC-AUC** — оценивает качество ранжирования независимо от порога.

### 4.2 Матрица ошибок

```
                    Предсказание
                 Чистый    Грязный
Истина  Чистый  [  TN   |   FP  ]
        Грязный [  FN   |   TP  ]
```

- **FP (False Positive):** чистый знак классифицирован как грязный → система запрашивает ручную проверку без необходимости
- **FN (False Negative):** грязный знак пропущен → OCR получит нечитаемый номер

В данной задаче FN критичнее, чем FP → при необходимости можно снизить порог классификации ниже 0.5.

### 4.3 Кривые обучения

По графикам обучения можно диагностировать:

| Паттерн | Диагноз | Решение |
|---|---|---|
| Train loss↓, Val loss↑ | Переобучение | Больше аугментации, Dropout, меньше эпох |
| Обе кривые высоко | Недообучение | Больше эпох, выше LR, сложнее модель |
| Обе кривые сходятся | Хорошо | — |
| Val loss скачет | Нестабильность | Меньше LR, больше batch |

### 4.4 ROC-кривая

ROC-кривая показывает компромисс между чувствительностью (TPR) и специфичностью (1-FPR) при разных порогах классификации. AUC (площадь под кривой):
- AUC = 1.0 → идеальная модель
- AUC = 0.5 → случайное угадывание
- AUC > 0.9 → отличный результат для нашей задачи

## 5. Выводы и рекомендации

### Ключевые выводы

1. **Transfer Learning критически важен** при малых датасетах. EfficientNet-B0, предобученный на ImageNet, содержит признаки, напрямую применимые к задаче различения текстур чистых и грязных поверхностей.

2. **Двухфазное обучение** (frozen → fine-tuning) обеспечивает стабильную сходимость: в Фазе 1 модель быстро учится отличать классы, в Фазе 2 тонко подстраивает признаки под специфику датасета.

3. **Аугментация** — ключевой инструмент при работе с малыми датасетами. Она не только расширяет обучающий набор, но и обеспечивает инвариантность к условиям съёмки.

4. **Баланс классов** в нашем датасете идеален — дополнительные техники (oversampling, class weights) не требуются.

### Рекомендации по улучшению

**1. Увеличение датасета (самый важный фактор)**
Даже 200-300 дополнительных размеченных изображений значительно улучшат качество модели. Рекомендуется сбор данных в разных условиях: разное время суток, погода, угол съёмки.

**2. Test-Time Augmentation (TTA)**
При инференсе применяем несколько аугментированных версий каждого изображения и усредняем предсказания. Улучшает результат на 1-3% без дополнительного обучения.

```python
def tta_predict(model, image_path, n_augments=5):
    predictions = []
    for _ in range(n_augments):
        img = train_transform(Image.open(image_path).convert('RGB'))
        prob = model(img.unsqueeze(0)).softmax(1)[0, 1].item()
        predictions.append(prob)
    return np.mean(predictions)
```

**3. Псевдолейблинг**
Берём наиболее уверенные предсказания на тестовом наборе (P > 0.95 или P < 0.05) и добавляем их в тренировочный набор → переобучаем модель → итерируем.

**4. K-Fold Cross-Validation**
С 40 примерами разные сплиты дают разные результаты. K-Fold (k=5) даёт надёжную оценку реального качества модели.

**5. Ансамблирование**
Обучаем несколько моделей с разными seed и архитектурами (EfficientNet-B0, ResNet-50, MobileNetV3), усредняем предсказания → снижение дисперсии.

**6. Более мощные backbone**
EfficientNet-B3 (81.6% ImageNet, 12M параметров) может дать прирост при наличии большего датасета.

**7. Специализированная предобработка**
Применить детектор номерного знака (YOLO, EasyOCR) для выравнивания и кропа знака перед классификацией — уменьшит шум от фона.
